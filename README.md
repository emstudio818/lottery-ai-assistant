# 大樂透 AI 助手

一個基於 React + TypeScript + Vite 的台灣大樂透分析工具，具備 AI 分析、歷史記錄管理、回測分析和搖獎機模擬功能。

## 功能特色

- 📊 **首頁熱度分析**：49 球熱力圖、號碼頻率分析、AI 推薦號碼
- 🎰 **搖獎機模擬**：視覺化開獎過程，增加娛樂性
- 📜 **歷史記錄管理**：手動新增開獎結果，數據持久化
- 🔍 **回測分析**：驗證推薦策略的歷史表現
- 📈 **數據分析**：共現關係、遺漏值、趨勢圖表

## 技術棧

- **React 18** - UI 框架
- **TypeScript** - 類型安全
- **Vite** - 建構工具
- **Tailwind CSS** - 樣式框架
- **React Router** - 路由管理
- **Chart.js** - 圖表
- **Lucide React** - 圖標

## 快速開始

### 安裝依賴

```bash
npm install
```

### 開發模式

```bash
npm run dev
```

應用將在 [http://localhost:3000](http://localhost:3000) 啟動。

### 生產建置

```bash
npm run build
```

### 預覽建置結果

```bash
npm run preview
```

## 使用說明

### 首頁

- **49 球熱力圖**：顯示每個號碼的出現頻率，紅色為熱門號碼，藍色為冷門號碼
- **AI 推薦號碼**：根據歷史數據提供 8 組推薦號碼
- **號碼頻率**：顯示出現次數最多的前 15 個號碼
- **遺漏值分析**：顯示最久未出現的號碼

### 搖獎機

- 點擊「開始搖獎」模擬開獎過程
- 號碼會一個一個逐漸確定
- 點擊「重置」可以重新開始

### 歷史記錄

- 檢視所有開獎歷史
- 手動新增新的開獎結果
- 重置數據至預設狀態

### 回測分析

- 檢視推薦策略的歷史表現
- 查看中獎記錄和詳細資訊

## 數據來源

預設包含台灣彩券官方真實開獎數據（民國 115 年第 49 期至第 71 期），並透過固定模擬數據補足至 100 期，確保分析結果穩定。

## 數據管理

- 使用 `localStorage` 持久化數據
- 新增開獎結果後，所有分析數據會自動重新計算
- 可隨時重置為預設數據

## 注意事項

- 此工具僅供學習和娛樂使用
- 樂透開獎為隨機事件，AI 分析不代表實際中獎機率
